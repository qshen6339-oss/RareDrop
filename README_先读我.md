# RareDrop｜稀有掉落

卡牌与手办收藏拍卖网站。前端使用 Vue 3，后端沿用课程起始项目的 Node.js、Express 和 SQLite。界面为英文，便于对应英文接口规范与演示；以下运行说明为中文。

## 现在怎么打开

本机预览地址：**http://127.0.0.1:5173/**。

预览停止后，在这个文件夹中双击 **START_RAREDROP.cmd**。保留运行窗口，浏览器打开上述地址。按 Ctrl+C 停止服务。如果提示端口已占用，说明已有一份后端或前端正在运行，直接访问预览或先关闭原运行窗口。

项目初次运行会在后端创建 `db.sqlite`，填入 3 个演示账户和 6 件虚构拍品。已存在的数据会保留，不会因再次启动被清空。演示拍卖时间在首次填入数据时计算，之后会自然到期。

## 换电脑或从 ZIP 解压后

需要 Node.js **22.12 或更新版本**。源码 ZIP 按作业要求不包含 `node_modules` 和运行中的数据库。

先在 `backend-server` 文件夹打开终端：

```text
npm ci
```

再在 `frontend-app` 文件夹打开终端：

```text
npx pnpm install --frozen-lockfile
npm run build
```

最后回到 RareDrop 主文件夹双击 `START_RAREDROP.cmd`，或执行：

```text
node start.cjs
```

前端锁文件为 `pnpm-lock.yaml`，其中允许 esbuild 的必要构建脚本。首次安装需要联网；字体与拍品图片已包含在项目内，运行时无需访问外部素材服务。

## 开发时怎么运行

后端在 `backend-server` 中运行课程原有命令 `npm run dev`，端口为 3333。

前端在 `frontend-app` 中运行 `npm run dev`，端口为 5173。前端开发服务器把 `/api` 请求转发给后端。当前受限 Windows 环境中依赖预打包可能遇到目录访问限制，已验证的运行方式是 `npm run build` 后使用 `npm run preview`，或使用主文件夹的启动脚本。

修改源码后，若使用构建预览模式，应重新执行 `npm run build`，然后刷新浏览器。启动脚本在缺少构建输出时才自动构建，已有构建不会被重复覆盖。

## 已实现的功能

- 用户注册、登录、退出，查看本人和其他收藏者资料。
- 浏览与按拍品名称搜索，分类过滤，分页。
- 发布拍品，设置起拍价和结束时间；一个拍品可关联多个分类。
- 详情页显示卖家、出价、最高出价者、出价记录与剩余时间。
- 出价由后端校验；禁止卖家自竞价、无效金额、未登录出价和到期后出价。
- 买家提问、卖家回答及更新回答，问题按最新在前展示。
- 我的在售拍品、我参与竞价的拍品、已结束的本人拍卖。
- 新拍品与问题的英文不文明用语过滤。
- 浏览器本地草稿：保存不完整表单、查看、编辑、删除、发布后移除草稿；按用户账户分开存储。
- 加载、空数据和错误提示，移动端布局，键盘焦点、可跳转正文与详情标签页键盘操作。

基础 API 没有图片上传接口。新发布的拍品使用明确的“未提供照片”状态，演示拍品使用原创示意图。未擅自加入购物车、支付、管理员审核等不在本次范围内的系统。

## 测试结果和复现

验证使用 Node.js 24.19.0。前端生产构建成功；独立后端检查 **18/18** 通过；草稿存储检查 **7/7** 通过。

**老师原测试为 120/128 通过，并非全通过。** 8 项失败与起始项目测试数据及预期不一致有关，详细数值、连带影响及规范依据见 `verification/TEST_NOTES.md`。原测试与样例数据保持原样，业务实现没有为通过这些预期而降低起拍价规则或修改搜索语义。最终评分仍以老师的完整测试和人工评阅为准。

重跑后端验证前，先停止正在运行的后端（释放 3333 端口），然后在主文件夹运行：

```text
node verify.cjs
```

该脚本为两组测试分别创建临时数据库，不清空演示数据库。脚本会保留原测试报告，并以独立检查是否全部通过决定退出状态；退出 0 不代表老师的原测试全部通过。

草稿检查在前端文件夹运行：

```text
node check-drafts.mjs
```

草稿检查验证真实存储模块，模拟浏览器存储与容量错误；不是浏览器点击测试。当前没有完成浏览器自动化回归或录屏，请按演示流程在实际浏览器中检查页面。
